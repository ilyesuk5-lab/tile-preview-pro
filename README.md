# Tile Preview Pro

أريد منك بناء وتطوير تطبيق ويب احترافي كامل باسم:

TileVision

الوصف المختصر:

"شوف كيفاش رايح يخرج الفايونص قبل ما تركبو"

هذا التطبيق مخصص لأصحاب مشاريع الفايونص، المبلطين، المقاولين، والمصممين.

المشكلة التي يحلها التطبيق:

العميل يريد أن يصور المكان الحقيقي، يدخل قياسات الجدران والأرضية، يدخل قياسات حبة الفايونص، ثم يرى كيف سيتم توزيع الحبات والقصاصات فعليًا قبل بدء التركيب.

المطلوب منك ليس مجرد تصميم واجهة.

أريدك أن تنفذ التطبيق كاملًا داخل Lovable:

Frontend + Backend + الحسابات الهندسية + SVG Layout + Image Generation + تقرير نهائي + معالجة الأخطاء.

لا تكتفِ بإنشاء mockup.

لا تستخدم أرقامًا وهمية.

لا تجعل الأزرار شكلية.

كل زر يجب أن يؤدي وظيفته فعليًا.

5. التوزيع المتوازن

==================================================

أريد خوارزمية تفكر مثل المبلط المحترف.

إذا كان الباقي صغيرًا جدًا في جهة واحدة، حاول موازنته بين الجهتين عندما يكون ذلك منطقيًا.

مثال:

الجدار = 300cm

البلاطة = 120cm

لا تفترض دائمًا:

120 + 120 + 60

يمكن أن يكون التوزيع الأفضل:

30 + 120 + 120 + 30

حسب نقطة البداية وقواعد التوازن.

يجب أن تكون هناك قاعدة تمنع القصاصات الصغيرة جدًا عندما يمكن تفاديها.

22. أنا لا أملك API لتوليد الصور

==================================================

هذه نقطة مهمة.

لا توقف المشروع بسبب عدم وجود API لدي.

أريد منك تنفيذ architecture كامل لتوليد الصور.

استخدم backend/server-side function.

لا تضع أي API key في frontend.

اجعل مفتاح المزود Secret.

إذا كانت ميزة توليد الصور تحتاج مزودًا خارجيًا أو API Key، قم بإنشاء التكامل والـ Edge Function والبنية كاملة، ثم اطلب مني Secret فقط عند الحاجة.

لا تضع المفتاح في source code.

Lovable يجب أن يستخدم الـ Secrets/Cloud backend بشكل آمن.

إذا كان لا يوجد API بعد:

- التطبيق يجب أن يعمل بالكامل في الحساب والمخطط

- المعاينة الواقعية يجب أن تكون optional

- لا يفشل التطبيق كله بسبب فشل AI
